# Как понято задание

«Новичок» — человек в первые 90 дней. Компания: опт и розница спорттоваров, около 400 человек, магазин, склад, отдел продаж, офис. Приём и увольнение уже идут задачами в Битрикс24. За год приходит больше ста человек, и каждый третий из ушедших не доработал до трёх месяцев.

Дыра между задачей «приняли» и задачей «уволили». За четыре часа нужно одно работающее действие для того, кто может этот уход остановить. Выбран прямой руководитель.

Короткий отчёт для сдачи — `ОТЧЁТ.md`, не длиннее 15 строк.

## Сценарий

Руководитель открывает свою доску.

- «Разобрать сейчас» — просроченная точка, пропущенный разговор или тревожный ответ.
- «Точка сегодня» — обычная задача со сроком сегодня. Это ещё не просрочка.
- «Идёт по плану» — сигналов нет.

На карточке он закрывает точку, называет наставника по имени или пишет, что сделал с тревожным ответом. После этого карточка замолкает.

## Правила сигнала

| Что случилось | Что на доске |
|---|---|
| Точка плана просрочена | «Просрочено», блок «разобрать сейчас» |
| Обычная точка со сроком сегодня | «Сегодня», отдельный блок |
| Разговор на 14-й или 45-й день наступил, ответов нет | Сигнал сразу, даже в день срока |
| Ответ «нет», «частично», «не знает, к кому идти», «сомневается» | Сигнал, пока руководитель не напишет, что сделал |
| Все три ответа спокойные | Разговор закрыт, сигнала нет |
| Настал 90-й день, решения нет | Три кнопки: остаётся, ещё месяц, расстаёмся |
| Решение записано | Карточка замолкает |
| Вышел сегодня, наставник назван | План есть, просрочки нет |
| Наставник пустой, день выхода уже прошёл | «Назначить наставника» |
| Дата выхода в будущем | Форма не сохраняет |
| Тот же разговор второй раз | «Разговор уже записан» |
| После 100-го дня | Человек сходит с доски |

План зависит от роли.

- Продавец: учебный чек, первая смена, допуск в зал.
- Кладовщик: техника безопасности, сборка, приёмка.
- Менеджер опта: живые звонки, десять своих клиентов.
- Офис: доступы в почту, Битрикс и 1С. Пока их нет, человек сидит.

Новичок видит свои точки, чужие просроченные и может ответить на три вопроса. Точки закрывает руководитель.

## Что совпадает с заданием

Задание оценивает выбор задачи, работу основного сценария и честность отчёта. Сделано для руководителя, данные вымышленные, четыре среды компании на месте. Битрикс24, учебная платформа и дашборд текучести не делались: годовую цифру в компании уже знают, в эти часы она не меняет первую неделю.

## Дыры

Решение «ещё месяц с планом» только записывается. Точек на этот месяц нет. К 100-му дню человек уходит с доски.

Если на 90-й день решение не нажали, после 100-го дня карточка тоже исчезает. Молчание перестаёт быть видно.

Новичок свои точки только читает, кнопки «сделано» у него нет. Если он отправил разговор с пустыми ответами, текст ошибки на его страницу не выводится.

Входа нет. Кто открыл ссылку, может закрыть чужую точку. Для показа за четыре часа этого хватает. Для ежедневной работы руководителя нет.
