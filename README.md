# Новичок

Первые 90 дней для руководителя магазина, склада, опта или офиса.
Между задачей «приняли» и задачей «уволили» в Битриксе здесь живёт план и сигнал, если точка просрочена.

Люди в базе вымышленные. Сроки считаются от сегодняшнего дня, поэтому доска не протухает.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --port 8765
```

Открыть http://127.0.0.1:8765 — доска Ольги Семёновой.

Проверка правил сигнала:

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Сбросить вымышленные данные: удалить `data/novice.sqlite` и запустить снова.
